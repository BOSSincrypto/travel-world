# Data and asset attributions

The MVP ships a deliberately lightweight, stylized map and a local UN-195 country catalog. It does not bundle third-party boundary geometry yet.

- Country scope: 193 United Nations Member States plus the Holy See and the State of Palestine (195). See the [United Nations Member States reference](https://www.un.org/en/library/unms).
- Planned metadata refresh source: [GeoNames countryInfo.txt](https://download.geonames.org/export/dump/countryInfo.txt), CC BY 4.0. When imported, keep the source URL, retrieval date, version/hash, and an attribution line.
- Planned boundary source: [Natural Earth](https://www.naturalearthdata.com/about/terms-of-use/), public domain. Keep the recommended “Made with Natural Earth” credit when the optional TopoJSON map asset is enabled.
- Journal starter photos are remote Unsplash image URLs used as demo content. User media is never uploaded by this client-only MVP.
